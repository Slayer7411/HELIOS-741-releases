◆ 1 · INSTALL

01

download HELIOS-741.dmg, open it, drag HELIOS into Applications.

02

start HELIOS. if macos blocks it: system settings -> privacy & security -> OPEN ANYWAY.

03

the setup assistant opens on the first start. it walks you through home, library and apps. you can run it again later from LIBRARY.

◆ 2 · CHOOSE A HOME

the home is the folder that holds your library file, its backups and exports.

  • google drive (default My Drive/741): same library on every mac you sign in on
  • local folder: anywhere on this mac
  • existing home: already set up on another mac -> pick it, HELIOS shows a summary before it adopts it

◆ 3 · THE LIBRARY

all 741 apps share one library file: collection.741. tracks, cues, grids, tags, playlists, sets and settings live in it. MINOS, STYX and ORPHEUS read and write the same file, so a cue you set in one app is there in the next.

start with your existing collection

  • import: reads an .nml or .xml collection (or an existing MINOS data folder) once
  • HELIOS shows a plan first: number of tracks and playlists, missing files, duplicates, warnings. nothing is written by the plan
  • you confirm, HELIOS writes the library and reads it back to check it. optional: it keeps a copy of the source under imports/<date>/

your music files

  • adopt: your music stays where it is, the library just points at it
  • move: HELIOS moves it into one library folder. files are only removed from the old place after the copy is verified

backups and exports

  • backups run automatically: hourly, weekly, monthly, yearly
  • when you close, the library is exported back to the common formats (.nml / .xml) under exports/. nothing gets locked in

later

LIBRARY in HELIOS: move, adopt, import, reset, run setup again. changes are refused while a deck is playing.

◆ 4 · REPAIR

  • checks every track in the library: does the file exist, does it decode
  • moved files are found again and relinked, cues and grids stay
  • runs in the background too, never while you play

◆ 5 · APPS AND UPDATES

  • install MINOS, STYX and ORPHEUS from HELIOS, one click each
  • channel per app: newest build (default), stable versions, own folder, or off
  • every download is checked before install. the last 3 versions are kept for rollback
  • no update while an app plays: HELIOS asks you to quit, or installs on the next quit
  • HELIOS updates itself the same way

◆ WITHOUT HELIOS

every app keeps its own updater and setup. MINOS alone: brew install --cask slayer7411/tap/minos-741
